# 电量进度条更新

0.2.2 支持 Factorio 2.0.77；0.2.3 支持 2.1.21 experimental。

建筑原生窗口顶部新增电量进度条，填充比例直接取真实电池 `LuaEntity.energy / 36,000,000,000`，限制在 0–1。条内显示简体中文或英文的剩余百分比（保留一位小数），下方继续显示精确 MJ、生命值和核爆半径。与现有窗口一起每 30 tick 刷新，重新打开立即读取电池。已打开的旧窗口缺少控件时安全跳过，重新打开显示新布局。

使用原版 `progressbar` 和 `electric_statistics_progressbar`，未引入额外资源或运行依赖。这两个游戏版本的原版 campaign 代码均直接使用原生进度条的 value/caption/style；两个版本的 core 样式均包含选用的样式。只修改 GUI 和本地化，不改电量标签、电网、信号或核爆逻辑。

已执行：

- 两版源码全部 Lua 5.2 语法与 JSON 检查通过。
- 现有 GUI 打开、刷新、手动确认、超时和物品电量逻辑检查通过，使用 API doubles；不是图形客户端验收。
- 两版最新安装 ZIP 的真实引擎生命周期场景通过：原生加载、机器人建造/精确回收/再放置、孤立采矿实际产出、雷达扫描、信号、克隆和回收清理。
- ZIP 运行文件与源码逐文件一致，校验值更新至 releases/SHA256SUMS.txt。

原始日志位于 `test-results/releases/0.2.2/` 和 `test-results/releases/0.2.3/`。完整标签与核爆回归仍对应历史 0.2.0/0.2.1 的 [TAG-INTEGRATION.md](TAG-INTEGRATION.md)；此次 UI 修改不冒用历史完整回归为新 ZIP 全套验收。

尚未执行真实图形客户端的进度条视觉和玩家点击验收。可在游戏中选中建筑，按 Ctrl+Shift+N，观察满电、半电、零电量及充放电时的条形与数字变化。
