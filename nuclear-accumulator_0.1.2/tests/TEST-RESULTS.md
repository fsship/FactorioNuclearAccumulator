# 验收结果 — 2026-10-09

使用实际官方 Linux headless **Factorio 2.0.77 stable** 和 **Factorio 2.1.21 experimental**。均只启用 base、主 Mod 和专用测试 Mod，Space Age / quality / elevated-rails 全部禁用。

本报告不把未执行项目标为通过。两版各运行一个 2,900 tick 的核爆/电网场景、一个 4,900 tick 的机器人生命周期场景。最终隐藏雷达图片改为与 1×1 empty.png 匹配的 `direction_count=1` 后，两版均再次加载并完整运行生命周期回归。爆炸代码没有随这项视觉修正改变。

## 测量与性能

最终两版核爆场景在同一主机并行运行；这些数字是这次场景的总平均，不是单座建筑平常的开销，也不能用于公平比较两版引擎性能。

| 场景 | 2.0.77 | 2.1.21 |
| --- | --- | --- |
| 电池放电，J/s | 约 5,000,000 | 约 5,000,000 |
| 电池充电，J/s | 约 5,000,000 | 约 5,000,000 |
| 孤立雷达消耗，J/s | 约 300,167 | 约 300,167 |
| 核爆场景 2,900 tick 平均更新 | 30.771 ms | 30.357 ms |
| 核爆场景最大单 tick | 1,276.924 ms | 1,283.116 ms |
| 生命周期场景 4,900 tick 平均更新（最终视觉修正前） | 0.287 ms | 0.192 ms |

满电效果是真的 200,000 个伤害弹道，含原生内部子效果；额外烟雾/视觉数量未乘 100。大型核爆有明显卡顿，不能保证 60 UPS。全部保留密度和无限制连锁与低峰值开销不能同时保证。

原生 area 随机分布、小爆炸自身半径和概率覆盖意味着受伤边界不是绝对硬圆。未在任意角度的每一个格子验证“必伤/必死”；静态原型公式和实际近远位置样本分别提供了不同范围的证据。
