# 图形客户端及扩展兼容性验收

这些步骤尚未在图形客户端执行。不要把逻辑测试或 headless 测试当成外观和真实玩家点击验收。使用新测试存档及与游戏版本匹配的 Mod 包。

## 玩家放置、GUI 和回收

1. 研究原子弹，确认配方显示 20 处理器、20 炸药、60 铀-235。原版原子弹材料、弹药和发射仍与未安装本 Mod 时相同。
2. 制造并由玩家放置新物品；鼠标指向主建筑，按 Ctrl+Shift+N，确认显示约 36,000 MJ、生命值 1,000、倍率约 10。雷达会立即开始耗电，真实电量可能已经略低于上限。
3. 确认主外观、组合图标、地图标记、中文/英文文本、所有按钮布局正常。选择覆盖附近的配电站供电框，检查 18×18 格供电范围。
4. 点击“准备手动引爆”后关闭窗口，应不引爆。重新打开准备引爆，等 11 秒再点击确认，应不引爆。
5. 再次准备并在 10 秒内确认，应引爆一次；窗口关闭，地图标签和全部隐藏辅助实体删除。
6. 新造另一座，由玩家正常采矿，确认得到同名物品且没有爆炸。再次放置应恢复拆除时余电，重复几次都不恢复出厂满电。另将真实电池设为 0 J 后回收，检查标签明确为 0，再放置仍为空电。确认每个物品占一格。

测试用控制台（仅在测试存档使用）可直接发放物品：

```lua
/c game.player.insert{name="nuclear-accumulator",count=10}
/c game.player.force.technologies["atomic-bomb"].researched=true
```

## 蓝图和电路

1. 连接红、绿线到主建筑；使用电路指示灯/算术组合器观察 E/H/P。孤立蓄电站持续供电后 E、P 应下降；受到少量伤害后 H 应在 0.5 秒内更新。
2. 使用新造与回收重建的实体分别制作蓝图；验证每站只包含一个主实体，都请求同一物品，铜/红/绿线可以复制。仅提供回收品也能建造新制品的蓝图；余电以消耗物品标签为准。
3. 在两个独立网络分别设置 D=0 和 D=1；只应引爆接入 D=1 的站。相同电路中多个站输出相加属于原版网络行为。
4. 保存半充电的多座站，退出并重载，确认电量未重置、没有新的隐藏实体副本、雷达/信号继续工作。
5. 检查同阵营选中控制与其他阵营选择时不允许手动控制的行为。测试多人分别打开窗口的状态是否相互独立。

## 半径、传播和密度的人工观察

在开阔地区，选中站后通过实际电池接口设置电量：

```lua
/c local e=game.player.selected; local s=remote.call("nuclear-accumulator","inspect",e.unit_number); s.battery.energy=18e9
```

0 J、18e9 J、36e9 J 分别对应档位 0、50、100。以当前原型元数据的 R0 为基准，布置近远多个方向的密集墙/工厂阵列，记录受伤开始 tick。预期半径倍率为 1、5.5、10，局部损伤范围还包含小爆炸本身的 3 格作用半径，因此覆盖边界并非理想硬圆。

自动测试已经验证 N/M² 和原生弹道参数，没有完成大样本、多随机种子、多方向的破坏率统计。若需要统计验收，应用多个相同材料/生命值阵列和随机种子，记录每单位面积受伤率/总伤害分布，而不能仅对比是否全部死亡。满电阵列测试和不限量连锁会造成明显 UPS 下降。

## 其他 Mod 和跨地表

测试具体目标 Mod 的搬运/克隆/升级操作是否发送标准建造/克隆/销毁事件。未发送事件的创建不会被周期全图扫描发现。测试地表清除、区块删除、force 合并和批量复制后是否残留辅助实体/地图标签。DLC 品质/地表规则、特殊电网以及改写核弹原型的 Mod 组合尚未全面验收。
